Como Jogar

  • Agitar: Dê uma leve sacudida no celular para jogar os dados pra cima.
  • Inclinar: Incline o celular como uma bandeja para fazer os dados deslizarem para os lados sob a gravidade.
  • Arraste: Toque e arraste um dado pela tela para movê-lo manualmente.

Nota: O giroscópio e o acelerômetro exigem sua permissão na próxima tela em alguns dispositivos (como iPhones).
