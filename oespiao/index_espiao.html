🕵️ O Espião

Descubra o espião ou engane a todos.

📖 Como Jogar

O Espião é um jogo de dedução, blefe e conversas desconfiadas.

🎯 O Objetivo

  • Os Agentes (A Maioria): Recebem um "Local Secreto". Devem fazer perguntas entre si para descobrir quem é o espião do grupo.
  • O Espião (1 Jogador): Não sabe onde está. Deve prestar atenção nas perguntas e respostas dos outros para tentar adivinhar o local sem ser notado!

🗣️ Como Funciona

  • O Host distribui os papéis, todos leem em segredo e a discussão começa.
  • O Jogador A escolhe alguém e faz uma pergunta sobre o local.
    (Ex: "Você costuma vir aqui de uniforme?")
  • O Jogador B responde e faz uma pergunta para uma terceira pessoa.
Cuidado: Perguntas muito óbvias entregam o local para o espião. Perguntas muito vagas fazem os outros acharem que VOCÊ é o traidor!

🛑 Fim da Rodada

O jogo pode ser interrompido pelo Host de duas formas:

  • 🚨 Acusação (Votação): Se o tempo acabar ou o grupo suspeitar de alguém, o Host libera a votação. Todos votam no celular em quem acham ser o Espião.
  • 👁️ Revelação (Palpite): Se o Espião achar que descobriu o local, ele grita "Pausa!", revela sua identidade e usa seu celular para dar o palpite final.
