Orientações do Sistema

💾 Como funciona a Persistência de Dados?

Os dados criados neste sistema "moram" no navegador do seu aparelho (PC ou Celular) que está sendo usado no momento, e não "na internet".

⚠️ É sua responsabilidade garantir a segurança desses dados fazendo backups regulares.

♻️ Rotina de Backup

Recomendamos fortemente exportar seus dados (fazer backup) no final do dia ou após cadastrar muitos itens de uma vez. Para isso, clique no ícone de exportar (nuvem com seta para baixo) ao lado deste botão de ajuda.

Dica: Salve o arquivo com uma data, ex: Orçamento_Backup_06-03-2026.json.

📱 Transferência entre Dispositivos

  • 1. Exporte o arquivo de backup no dispositivo atual (ex: PC).
  • 2. Envie esse arquivo para o outro dispositivo (via WhatsApp, Email, Google Drive, etc).
  • 3. Acesse o sistema no novo dispositivo e clique no ícone de importar (nuvem com seta para cima).
  • 4. Selecione o arquivo .json recebido e pronto!

🚨 Alertas e Cuidados Adicionais

  • NUNCA limpe os dados do navegador (cache/cookies) sem ter feito o backup antes. Limpar o histórico ou usar programas como CCleaner irá deletar o sistema inteiro e todo o seu progresso.
  • NUNCA use Guia Anônima! Se o sistema for aberto e alimentado em aba/guia anônima, os dados não serão salvos e serão perdidos assim que você fechar a aba.
  • Backup em Nuvem: Evite deixar o backup (.json) perdido no aparelho. Suba o arquivo regularmente para plataformas como Google Drive, OneDrive ou envie pelo WhatsApp, mantendo seus dados protegidos contra falhas no dispositivo.
  • Logo e Imagens: Para evitar que a memória seja esgotada rapidamente, recomendamos usar logos leves nas configurações (evite grandes arquivos).
